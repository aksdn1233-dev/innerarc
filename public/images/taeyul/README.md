# 태율 expression set

Eighteen expressions, sliced from the supplied contact sheet at its native resolution.

Each file is **242×230**. That is their real size — the sheet was 1536×1024, so this is
everything there is, not a downscale. They are sharp at up to about 240 CSS px, which makes
them character insets beside a speech bubble, the way the reference result page uses its
small character art. They are **not** full-width panels: a phone panel is 1080px, and
enlarging these to that would be a visibly blurred picture.

For full-width panels the individual source PNGs are needed. See
`docs/Taeyul-Webtoon-Assets.md`.
