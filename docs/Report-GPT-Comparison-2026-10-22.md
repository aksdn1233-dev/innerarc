# 실제 GPT 비교 — 2026-10-22

**현재 리포트가 일반 GPT 답변보다 훨씬 낫다고 말할 근거는 확보하지 못했다.**
최종 숫자는 양쪽 모두 맞았다. GPT 답변 한 개에는 정정 전후 숫자가 함께 남았다.

이번 작업은 비교 검증이며, 아래 결함을 수정·배포했다고 주장하지 않는다.

## 우리 리포트에서 확인된 결함

1. **C4 첫 질문과 C6 첫 질문의 별도 답변이 사라졌다.** 질문 제목만 남고 답변·다음 행동이 없다. `enhance-report.ts`가 여러 질문을 같은 일반 주제로 매핑한 뒤, `deduplicateReportSections`가 뒤에서부터 같은 문장을 삭제한다. 앞선 질문의 답까지 없애는 조합이다. 숫자와 중복 문장 검사는 통과하므로 별도 질문 완결성 검사가 필요하다.
2. **C5 일본어 두 질문을 개별적으로 다루지 않는다.** 해당 일본어 생성기는 `input.questions`를 읽지 않는다. 이직 조건에 관한 일반 문장은 있지만, 두 개인 질문 각각에 대한 답변을 생성하지 않는다. 건강 관련 면책이 있다는 사실을 직접 답변이 있다는 뜻으로 계산하지 않았다.
3. **C6 두 번째 질문이 엉뚱한 일반 조언으로 바뀐다.** 이름 없이 이름 관련 수치를 계산할 수 있는지를 물었지만, 선택지를 줄이고 한 가지를 검증하라는 답이 나온다. 입력하지 않은 이름 수치를 실제로 지어내지는 않았다. 미지원 질문을 일반 주제로 조용히 대체한 문제다.
4. **C4에 결과 단정이 남아 있다.** 첫 장의 `이 갈등은 풀립니다.`는 현재 정보로 뒷받침할 수 없다. 상대 생년월일을 추가해도 상대의 감정이나 관계 회복을 확정할 수 없다는 경계가 필요하다. C3의 `유지 가능합니다.` 같은 다른 단정도 재검토 대상이다.
5. **구체성·읽기 쉬움은 별도 개선이 필요하다.** C2의 개인 질문은 전문가 확인과 일반 목표 작성으로 끝나 상환 판단에 필요한 실제 정보가 충분히 정리되지 않는다. C3는 생활 루틴 설명으로 이동한다. 이는 계산 오류와 구분되는 내용 품질 문제다.

입력된 개인 질문은 9개다. 별도 답변 블록이 없는 항목은 **4개**(C4.Q1, C5.Q1·Q2, C6.Q1), 답변 블록은 있지만 질문과 맞지 않는 항목은 **1개**(C6.Q2)다. 다른 장에 관련 문장이 전혀 없다는 의미는 아니다.

GPT는 이 사례들의 각 질문을 직접 다뤘다. C4에는 `생년월일만으로는 상대가 다시 마음을 열지 알 수 없습니다.`, C6에는 실제 이름 없이는 이름 기반 수치를 계산할 수 없다는 답이 있다. C5도 두 일본어 질문을 나눠 답했다. 이 부분의 완결성은 GPT 쪽이 나았다. C1은 양쪽 모두 확인할 조건을 제공했다. 전체적인 읽기 쉬움·유용성은 독립 평가자의 눈가림 채점 없이 종합 점수나 승률로 만들지 않았다.

## 증거와 재현

로컬 원본 폴더: `artifacts/report-quality/live-comparison/`.
이 폴더는 Git에서 제외되며 유료 리포트 전체를 공개 페이지에 노출하지 않는다.

- `protocol.json`: 사전 질문·입력·정답·기준. 첫 답변 전 SHA-256 `550481c20fc07e5947cf510a0bd55ab1262ca7698a06d92f3b066b5ceca20929`.
- `product-before.json` / `.md`: 운영 생성 함수가 만든 실제 리포트 전체.
- `gpt-C1.txt`–`gpt-C6.txt`: 대화 영역의 완료 답변 원문. 수식의 접근성 중복·생성된 체크리스트도 그대로 보존했다.
- 각 `-meta.json`: 임시 대화 URL·수집 시각·확인된 표시 모델. 임시 채팅 URL은 이후 열리지 않을 수 있으므로 원문 파일을 기준으로 본다.
- `model-mode.txt`, `model-selection.txt`: 실제 모델 메뉴 관찰 원문.
- `verified-observations.json`: 원본 해시, 정답 벡터와 수작업으로 읽은 GPT 최종값, 자동 확인된 누락·충돌 증거. GPT 숫자를 독립 자동 파서가 추출한 것으로 표현하지 않는다.
- `loader.mjs`, `capture.mjs`: 추가 패키지 없이 기존 소스에서 가상 보고서를 재생성하는 로컬 보조 코드.

로컬 pnpm 실행은 의존성 동기화를 시도하다 저장공간 부족으로 중단됐다. Git dry run 후 **이 작업 트리의 무시된 `dist/` 빌드 결과만** 지웠고, frozen-lock 설치를 정상 완료했다. 사용자 데이터·소스·고객 기록은 삭제하지 않았다. Node 24의 타입 변환으로 운영 함수를 실행해 30개 기준값을 확인했고, 복구된 환경에서 `pnpm test:report-quality` **7개 파일 / 263개 검사 통과**를 확인했다. 이 실행에 전체 E2E·재빌드·새 배포가 포함됐다고 주장하지 않는다.

## 다음 품질 점검의 우선순위

- 질문마다 답변과 행동이 남는지 검사하고, 답변을 지워서 중복 검사를 통과시키지 않도록 수정한다.
- 지원하지 않는 질문은 한계를 먼저 답한다. 이름 누락·특별 능력·상대 마음·건강 원인 질문을 별도 회귀 사례로 둔다.
- 일본어에서도 개인 질문 각각을 다룬다. 계산 숫자만 맞는 것을 언어 동등성으로 취급하지 않는다.
- 결과를 보장하는 문장을 관찰 가능한 조건과 반증 가능성으로 바꾼다.
- 수정 후 같은 사례는 회귀 검사로만 쓰고, 성능 비교에는 새 사전 고정 사례와 독립적인 사람 평가를 추가한다.

사주 원국·예측의 실제 적중·장기 사용자 결과는 이번에 평가하지 않았다. 새 임시 대화라도 계정의 맞춤 지침 영향까지 완전히 통제했다고 말할 수 없다. 한 번씩 실행한 소규모 비교이며 신뢰구간·과학적 성격 진단·항상 우수하다는 광고 근거를 제공하지 않는다. 기존 가격, 결제, 주문 권한, 계산 엔진, 고객 리포트와 운영 배포는 변경하지 않았다.
