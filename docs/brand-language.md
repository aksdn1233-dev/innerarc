# 태령당 브랜드 문장 원칙

이 문서는 홈페이지와 상품 문구를 수정할 때 가장 먼저 확인한다.

1. 메인 슬로건에는 `수비학`, `AI`, 알고리즘 같은 기술 용어를 사용하지 않는다.
2. 서비스 범위를 관계에만 가두지 않는다. `타고난 나의 성향`, `학업·직업·연애`, `가까운 사람과의 관계`, `올해의 흐름`을 함께 설명한다.
3. 짧은 문장과 일상적인 단어를 사용한다. `관계 패턴`, `아키타입`, `수리 체계`처럼 설명이 필요한 말은 첫 화면에서 피한다.
4. 프리미엄 상품명에는 파일 형식인 `PDF`를 넣지 않는다. 상품의 가치와 얻는 결과를 이름으로 쓴다.
5. 결과 보장, 운명 단정, 가짜 후기, 근거 없는 인기·마감 표현은 사용하지 않는다.
6. 숫자를 사용하는 방식은 서비스 설명 영역에서 투명하게 밝히되, 브랜드의 첫 문장은 고객이 알고 싶은 삶의 영역과 올해의 흐름에 집중한다.
7. 화면에 예시로 보여주는 질문은 실제 리포트에서 답할 수 있어야 한다. 리딩할 사람의 생년월일을 입력받고, 답변에는 해당 생년월일에서 계산된 성향과 올해의 흐름을 반드시 반영한다.
