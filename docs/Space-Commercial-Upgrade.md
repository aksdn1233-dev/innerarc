# 3D 공간운 상용 품질 강화

## 범위

기존 직사각형 단일 방 V1의 좌표·규칙·저장 형식을 유지한다. 이번 변경은 브라우저 3D의 전체 보기, 방 안 보기, 현재/비교/추천 상태, 카메라 안전, 추천 설명, 대표 장면 검증을 강화한다. 인증·결제·리포트·사주·생년월일 패턴 계산은 변경하지 않는다.

## 사용자가 보는 상태

- **전체 보기**: 방 외곽과 모든 가구를 한 화면에 맞춘다.
- **방 안에서**: 침대 또는 소파 중심의 안전한 실내 시점을 선택한다. 시야를 확보하지 못하면 전체 보기로 돌아가고 그 사실을 알린다.
- **위에서**: 평면 배치와 통로를 확인한다.
- **현재 / 한눈에 비교 / 추천**: 실제 좌표가 바뀐 객체만 이동선과 윤곽으로 연결한다.

실내 카메라는 확인된 방 경계 안에 머물고, 높은 가구의 점유 면적에 들어가면 마지막 안전 위치로 돌아간다. 러그처럼 바닥에 붙은 물체는 이동을 막지 않는다.

## 대표 장면

자동 검증 장면은 작은 침실, 넓은 침실, 거실, 거실과 주방, 창이 많은 침실, 긴 방, 가구가 많은 방, 가구가 적은 방이다. 각 장면은 데스크톱·세로 화면의 전체/위 시점 프레이밍, 기하 경계, 렌더 예산을 검사한다.

## 명확한 제한

V1은 직사각형 방 한 개만 지원한다. 비정형 방과 여러 방을 연결한 집 전체 Dollhouse는 임의로 직사각형으로 바꾸거나 만들어 내지 않고 중단 안내를 보여준다. 사진은 가려진 구조와 절대 길이를 확정할 수 없으며, 사진 초안 분석 전 실제 벽 길이 하나가 필요하다.

## 되돌리기

기능 플래그 `SPACE_AI_ENABLED`로 AI 사진 읽기를 먼저 중지하고 `SPACE_ENABLED`로 새 분석을 중지할 수 있다. 이 변경은 DB migration이 없으며 브랜치의 직전 커밋으로 UI·카메라 변경을 되돌릴 수 있다. 기존 기록 조회·내보내기·삭제는 기능 플래그와 무관하게 유지한다.
