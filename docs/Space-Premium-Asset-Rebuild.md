# 3D 공간운 프리미엄 장면 재구성

## 1. 64b4f4c가 부족해 보인 이유

침대만 크게 잡힌 첫 화면에서는 실제 방이 넓어져도 책상과 옷장이 보이지 않았다. 창가에는 깊이를 만드는 천이 없었고, 큰 수납 가구의 어두운 단색 면이 시선을 끌었다. 사용자는 한눈에 방 전체의 생활 구성을 읽기 어려웠다.

## 2. 교체·개선한 자산

침실은 5.4×6.2m, 가구 8개로 다시 구성했다. 거실은 6.6×5.6m, 가구 9개로 다시 구성했다. 옷장은 밝은 오크 프레임과 패브릭 패널로 바꾸고, 모든 확인된 창에는 커튼 레일과 주름진 커튼을 표시했다. 거실에는 TV·책장·수납장을 추가했다.

## 3. 자산 출처와 이용 조건

새 커튼·옷장·책상·침대·수납 가구는 프로젝트 소유 절차형 형상이다. 소파는 Khronos glTF Sample Assets의 GlamVelvetSofa(CC BY 4.0), 의자는 SheenChair(CC0), 식물은 DiffuseTransmissionPlant(CC BY 4.0), 바닥·패브릭·베니어·환경광은 Poly Haven(CC0)을 사용한다. 원본·최종 폴리곤 수, 텍스처 해상도와 최적화 내용은 `public/space/assets/manifest.json`에 기록했다.

## 4. 형상 개선

옷장 문짝, inset 패널, 손잡이, 상·하부 프레임을 분리했다. 커튼은 평평한 상자가 아니라 세분화된 천 표면에 이중 주름을 적용했다. 벽 두께, 창 recess, 창틀, 걸레받이, 문선, 천장 모서리와 바닥 전환은 기존 교정 결과를 유지했다.

## 5. 재질 개선

옷장은 바닥과 구분되는 밝은 오크와 중성 패브릭을 사용한다. TV 화면은 완전한 검정 대신 낮은 발광과 청회색 반사를 갖는다. 바닥, 목재, 패브릭, 벽 plaster의 PBR 반응과 normal/roughness 분리는 유지했다.

## 6. 조명 개선

창 방향광, 환경 채움광, 천장 반사광, 실제 조명 가구를 분리한다. 창 쪽과 그늘 쪽의 밝기 차이는 남기면서 가구 접지 그림자와 어두운 면의 세부를 보존한다.

## 7. 카메라와 구도 개선

가로 화면의 첫 장면은 주 가구 반대쪽의 안전한 코너를 선택하고 62도 수직 화각으로 방의 생활 구성을 함께 담는다. 침대만 확대하지 않고 침대·책상·의자·옷장·창가의 깊이를 한 프레임에서 보여 준다. 세로 화면은 침대/소파 중심의 읽기 쉬운 기존 실내 구도를 유지한다. 전체 보기·방 안에서·가구 자세히·위에서 보기는 서로 독립적이다.

## 8. 창과 환경 개선

확인된 창의 크기와 위치는 그대로 사용한다. 시각화 커튼은 분석 객체가 아니며 충돌·추천 계산에서 제외된다. 창밖은 특정 장소를 꾸며내지 않는 중성 하늘 표현이고, 유리와 recess가 흰 구멍처럼 보이지 않게 깊이를 만든다.

## 9. 성능 측정

2026-09-10 headless Chromium SwiftShader 측정이다. 물리 기기 결과로 주장하지 않는다.

| 조건 | 실제 렌더 | 첫 준비 | 첫 렌더 | CPU 렌더 P90 | 호출 | 삼각형 | 텍스처 추정 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| HIGH desktop | 1352×1080, DPR 2.0 | 14.30s | 125.7ms | 3.6ms | 224 | 323,469 | 49.5MB |
| BALANCED desktop | 1014×810, DPR 1.5 | 14.02s | 104.3ms | 19.2ms | 224 | 323,469 | 49.5MB |
| MOBILE emulation | 486×540, DPR 1.5 | 10.92s | 101.3ms | 2.6ms | 206 | 289,685 | 49.5MB |

SwiftShader에서는 움직임을 즉시 적용하는 보호 정책이 작동하므로 평균 FPS, P95/P99 프레임 시간과 1% low는 만들지 않았다. 실제 GPU에서 12개 이상의 활성 프레임을 얻으면 새 계측 필드가 평균 FPS, 평균/P95/P99 프레임 시간과 1% low를 기록한다.

- [x] 벽이 완전한 흰색 flat shader로 보이지 않는다.
- [x] 가구가 바닥에서 뜨지 않는다.
- [x] 환경광 때문에 명암이 평평해지지 않는다.
- [x] 창이 과노출된 흰 구멍처럼 보이지 않는다.
- [x] 극단적인 광각 왜곡이 없다.
- [x] 첫 화면이 빈 편집기 화면처럼 보이지 않는다.

- [x] 단일 방의 건축적 크기가 믿을 만하다.
- [x] 자산 색과 재질 방향이 한 가지 현대 주거 스타일로 이어진다.
- [ ] 오프라인 path-traced 정지 이미지와 같은 사진 사실성은 목표·구현 범위가 아니다.

## 16. 남은 눈에 보이는 한계

책상과 옷장은 실시간 절차형 가구라 가까이 확대하면 고폴리곤 상용 시각화 자산보다 단순하다. 창밖은 중성 환경이며 실제 장소를 복원하지 않는다. 물리 iPhone/Android GPU 측정과 실제 사진 기반 방 추출은 이번 시각 작업에 포함하지 않았다.

## 17. 실제 품질 판단

첫 장면의 공간감과 가구 구성은 64b4f4c보다 즉시 넓고 풍부하게 보인다. 결과는 고급 실시간 웹 인테리어 configurator 방향이며, 오프라인 Unreal/Chaos 정지 렌더와 동일하다고 평가하지 않는다.

## 18. 변경 범위

카메라 구도, 예시 침실·거실 데이터, 커튼/옷장/TV 재질, 실측 프레임 계측, 비교 거리 안정화, 단위·브라우저 회귀와 시각 증거만 변경했다. 결제·인증·사주·개인 패턴·저장 구조·AI 호출은 변경하지 않았다.
