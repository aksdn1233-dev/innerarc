# 태율 (太律) — character library and the webtoon result page

A 61-image library of the character was supplied as two contact sheets. This is what is in
it, what the result page intends to do with it, and what is still needed before that page
can be built.

## What the result page is meant to be

Not a report. A vertical webtoon the reader scrolls: a full-width illustrated panel, then a
speech bubble in which 태율 speaks to the reader by name, then the next panel. The
reference for this is `cheongwoldang.com/s/bluemoonladysaju/result`, recorded and studied.

The panel sequence follows the reading rather than the character sheet:

| Beat | Panel | Bubble |
| --- | --- | --- |
| Greeting | `01_정면_기본` or `47_미소_부드러운` | Reader's name, what is about to happen |
| Where the numbers come from | `18_계산_손동작` | The calculation, stated plainly |
| The core number | `43_먹과_붓_클로즈` behind the figures | The number and what it is |
| First insight | `49_웃음_장난기` | The tendency the numbers describe |
| The harder part | `54_분노_살짝화남` or `53_슬픔_우울` | What repeats and costs something |
| Depth | `51_진지_집중` | The pattern underneath it |
| Comfort | `60_측면_미소` | It is a tendency, not a verdict |
| Close | `61_측면_진지` | What to do with it |

Two things the reference does that this page will not. It runs a countdown to a discount
that resets per visitor; a timer here would have to track a real campaign end or not exist.
And it states outcomes as fact; this page's readings stay descriptive, as everywhere else
in the product.

## What is still needed

**The individual PNG files.** Only the contact sheets were supplied. Each cell in them is
roughly 245px wide, which is a thumbnail — a full-width panel on a phone needs 1080px, and
enlarging a thumbnail to that size produces a blurred panel that would look worse than no
illustration at all.

Sending the ~10 files named in the beat table above is enough to build the page; the rest
can follow. Any width from 1080px up is fine, PNG or JPEG.

Until they arrive the page cannot be built to look like the reference, and building it with
upscaled thumbnails would be worse than waiting.
