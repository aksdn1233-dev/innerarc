# InnerArc 결제·법률·운영 도메인 출시 체크리스트

기준일: 2026-07-27
상태: 구현 기반 완료, 실제 결제 비활성

이 문서는 개발·운영 준비용 체크리스트이며 개별 법률자문을 대신하지 않는다. 사업자 정보와 실제 계약서를 기준으로 최종 검토해야 한다.

## 1. 확정된 결제 구조

- 토스페이먼츠 V2 결제위젯을 단일 결제 진입점으로 사용한다.
- 가맹점 심사가 끝난 카카오페이, 토스페이, 가상계좌, 휴대폰 결제를 결제위젯 관리자에서 노출한다.
- Plus/Pro는 자동갱신 없는 30일 이용권이다. 가격은 환경변수로만 설정하며 코드에서 추측하지 않는다.
- 주문금액·상품·성공 및 실패 URL은 서버가 결정한다.
- 성공 URL의 금액은 신뢰하지 않고, 서버 주문 금액과 토스페이먼츠 조회 결과를 모두 대조한다.
- 가상계좌는 `WAITING_FOR_DEPOSIT` 상태에서 이용권을 주지 않는다. 토스페이먼츠 API 재조회 결과가 `DONE`일 때만 반영한다.
- 일반 결제 웹훅에는 결제 서명이 없으므로 본문만 신뢰하지 않고 토스페이먼츠 결제 조회 API로 다시 검증한다.
- 결제키와 시크릿키는 브라우저·공개 Supabase 테이블에 노출하지 않는다.

## 2. 결제 활성화 전에 받아야 하는 값

- 사업자 상호, 대표자, 사업장 주소
- 사업자등록번호, 통신판매업 신고번호
- 대표 전화, 고객지원 이메일, 개인정보 담당 연락처
- Plus 30일 가격, Pro 30일 가격(부가세 포함 여부 포함)
- 정확한 제공 기능과 제공 개시 시점
- 청약철회·취소·부분사용·장애·중복결제 환불 기준
- 운영 도메인
- Supabase 운영용 service-role 키
- 토스페이먼츠 라이브 결제위젯 클라이언트 키와 시크릿 키
- 충분히 긴 고객키 HMAC salt

## 3. 법률·고지 출시 게이트

### 통신판매

- 정부24에서 통신판매업 신고를 완료하고 번호를 받는다.
- 사이버몰 초기 화면과 결제 전 화면에 상호, 대표자, 주소, 전화번호, 이메일, 사업자등록번호, 통신판매업 신고번호 등 적용되는 신원정보를 표시한다.
- 결제 전 상품명, 가격, 공급 방법·시기, 청약철회와 환불, 분쟁처리, 거래약관을 사용자가 저장·확인할 수 있게 제공한다.
- 미성년자 거래를 허용할 경우 법정대리인 동의가 없으면 계약을 취소할 수 있다는 법정 고지를 구현한다. 허용하지 않을 경우 최소 연령과 확인 절차를 명확히 한다.

### 개인정보

- 개인정보처리자, 보호책임자 또는 담당부서, 권리행사 연락처를 확정한다.
- 처리 목적, 항목, 보유기간, 제3자 제공, 파기, 처리위탁, 안전조치, 권리행사, 자동수집 도구를 실제 시스템과 맞춘다.
- Supabase의 프로젝트 리전·하위처리자·계약 조건을 기준으로 국외이전 국가, 시점·방법, 항목, 보유기간, 거부 방법과 불이익을 확정한다.
- 토스페이먼츠와 실제 선택 결제수단의 개인정보 처리 역할을 계약서로 확인한다.
- 개인정보 처리방침을 홈페이지에 지속적으로 공개하고 변경 이력을 유지한다.

## 4. 운영 도메인 연결 순서

1. 실제 소유할 도메인과 배포 호스팅을 정한다.
2. 호스팅에서 제시하는 A/AAAA/CNAME 또는 검증 레코드를 DNS에 추가한다.
3. TLS 인증서 발급과 `https://운영도메인` 접속을 확인한다.
4. 운영 환경변수에 `NEXT_PUBLIC_APP_URL=https://운영도메인`, `APP_HTTPS_ONLY=true`, Supabase 키와 결제 값을 설정한다.
5. Supabase Auth의 Site URL과 허용 Redirect URL에 운영 도메인의 `/auth/callback`을 등록한다.
6. 토스페이먼츠 성공 URL, 실패 URL, `POST /api/payments/toss/webhook`을 운영 도메인으로 등록한다.
7. 카카오페이를 토스페이먼츠 결제수단으로 사용한다면 가맹점 심사와 위젯 노출을 확인한다. 직접연동을 별도로 추가할 때만 카카오페이 개발자센터 도메인도 등록한다.
8. 실제 소액 승인·취소, 가상계좌 발급·입금, 휴대폰 결제, 중복 웹훅, 실패 리다이렉트, 환불을 운영 전 점검한다.
9. 보안헤더, 로그 마스킹, 모니터링, 백업·복구, 고객지원 대응표를 확인한 뒤 `PAYMENTS_PROVIDER=toss`로 전환한다.

## 5. 현재 결제를 열 수 없는 이유

- 운영 도메인 미정
- 판매자 공개 정보와 통신판매업 신고번호 미입력
- 상품 가격·환불정책 미확정
- 토스페이먼츠 가맹점 및 결제수단 심사·라이브 키 미입력
- Supabase 결제 마이그레이션 및 service-role 키 미적용

이 값들이 없으면 앱은 결제 버튼을 비활성 상태로 유지한다.
