## 빠진 것

1. **AI가 꺼져 있습니다** (`AI_PROVIDER=disabled`). 지금 모든 리포트가 결정론적
   템플릿입니다. 반복 표현·개인화 부족의 근본 원인이 여기입니다.
   **켜기 전 선행 조건**: 약관과 개인정보 문서에 처리위탁 업체와 처리 국가를 명시해야
   합니다. 손님이 쓴 고민 텍스트가 워커 밖으로 나가기 때문입니다. 코드 문제가 아니라
   법적 문제이므로 코드로 우회하지 않습니다.
2. **무료→유료 실제 잠금 미리보기.** 지금은 상품 설명만 있고, 실제 유료 문단의 앞부분을
   보여주고 뒤를 잠그는 구조가 아닙니다.
3. **중복 표현 검증 계층.** 사용자 간 문장이 겹치는지 검사하는 곳이 없습니다.
4. **79k 개인 질문 2개** 입력·응답 경로.

- 실서비스: Cloudflare Worker `innerarc`. Vercel 아님. (계정에 남은 워커는 이것 하나입니다.)
- **도메인 연결은 끝났습니다.** apex `mygyeol.kr`이 `innerarc` 워커에 Custom Domain으로
  붙어 현재 빌드를 서빙합니다 (2026-08-08 `/ko`·`/ko/saju` 200 확인). `www.mygyeol.kr`은
  이제 존재하지 않습니다(NXDOMAIN). 이전에 적어둔 apex→www 리디렉션 규칙은 지금 넣으면
  살아 있는 주소를 죽은 주소로 보내므로 넣으면 안 됩니다. 자세한 내용은
  `docs/Operations-Runbook.md`.
- GitHub Actions 배포는 `CLOUDFLARE_API_TOKEN`/`CLOUDFLARE_ACCOUNT_ID` 시크릿이 없어
  실패합니다. 그때까지는 손으로 `wrangler deploy --keep-vars`.
