# Premium Korean editorial redesign evidence

Date: 2026-09-09

## Baseline and scope

The source of truth was production `main` at `2f23a13`. The app remains Next.js 16 with the App Router, React 19, server-owned payment pricing, deterministic Saju/numerology/tarot logic, Supabase account boundaries, Cloudflare deployment and the existing report/Reality Check/Space routes. This pass changes the shared visual tokens, public-home information architecture, home copy and one decorative hero asset. It adds no migration, API, provider request, customer field or entitlement.

## Final structure

1. Sticky charcoal navigation with the real service routes and a gold free-Saju action.
2. A 70–85vh Korean night hero with a direct free-Saju action and service-map link.
3. Four concise, supportable trust statements.
4. Five premium service cards for Saju, numerology, tarot, compatibility and 3D Space.
5. Warm-ivory analytical result preview with chart, evidence labels and short modules.
6. Existing sourced public comparison, relationship, 3D Space and Reality Check sections.
7. Existing legal, privacy and content-protection footer boundaries.

## Visual system

- Charcoal: `#101217`, `#15171D`, `#1C1B1A`
- Warm ivory: `#F7F3EA`, `#FBF8F2`, `#EFE8DC`
- Restrained gold: `#C9A86A`, `#D7B978`, `#B99556`
- Burgundy: `#651E25`, `#7D272E`
- Serif display hierarchy remains performance-safe; UI and Korean body copy use the existing system/Pretendard-compatible stack.
- Gold marks primary actions, selected states and important data. It does not fill ordinary cards.

The generated hero is text-free decorative brand art and contains no customer data or result claim. Its project source is a 1640×920 image compressed to a 328 KB JPEG; Next/Image keeps responsive delivery and stable dimensions.

## Preserved behavior

- Deterministic Saju, numerology and tarot calculations
- Compatibility, public comparison and Reality Check data paths
- Active server-owned prices and payment verification
- Authentication, saved/purchased reports, export and deletion
- 3D Space flags, storage, rendering and provider boundaries
- Analytics consent, SEO metadata, crisis resources and content protection
- Always-visible-on-home-load four-step guide, including keyboard containment and dismissal
